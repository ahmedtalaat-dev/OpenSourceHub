# 🤝 How To Add Yourself

After your Pull Request gets merged:

1. Open `contributors-list.md`
2. Add your information using the table format
3. Submit your changes

Example:

```md
| Ahmed Talaat | @ahmedtalaat-dev | React Project |
```
