## 📜 Code of Conduct

By participating in this project, you agree to follow our Code of Conduct.  
Be respectful, inclusive, and supportive of others.

---

## 🤝 How Can I Contribute?

You can contribute in many ways:

- 📚 Improve documentation
- 🐛 Fix bugs
- ✨ Add new features or projects
- 🎨 Improve UI/UX assets
- 🧠 Add learning resources
- 🧪 Write or improve tutorials
- 🔥 Suggest new ideas

---

## 🚀 Getting Started

- Fork the repository
- Clone your fork locally:
- Create a new branch:
- Make your changes
- Send PR

---

## 🔄 Contribution Workflow
- Make sure your code follows project structure
- Test your changes locally
- Commit your changes
- Push to your fork
- Open a Pull Request (PR)

---

## ✍️ Commit Message Guidelines

Use clear and meaningful commit messages:

- feat: add new React project
- fix: resolve broken link in README
- docs: update contributing guide
- style: improve formatting
- refactor: restructure projects folder

---

## 📥 Pull Request Rules

Before submitting a PR:

- Make sure your code works properly
- Follow folder structure of the repo
- Avoid duplicate content
- Write a clear PR description
- Link related issues if available

---

## 🧠 Project Structure Awareness

Please respect the structure of the repo:

- projects/
- courses/
- resources/
- open-source-guide/

Add files in the correct category only.

---

## ❓ Need Help?

If you need help:

- Open an Issue
- Ask questions in Discussions (if enabled)
- Or contact maintainers
