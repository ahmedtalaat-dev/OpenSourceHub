# Week 1 Challenge 🚀

Welcome to the first weekly challenge.

This week's challenge is focused on building a responsive XO (Tic Tac Toe) game using HTML, CSS, and JavaScript.

---

# 🎯 Challenge Goal

Build a modern and fully responsive XO game that works smoothly on both desktop and mobile devices.

The goal of this challenge is to practice:

- HTML structure
- CSS styling and responsive design
- JavaScript logic
- DOM manipulation
- User experience improvements

---

# 🛠️ Technologies

You must use:

- HTML
- CSS
- JavaScript

Frameworks are not allowed for this challenge.

---

# 📌 Challenge Requirements

Your XO game should include:

- Responsive design
- Two-player gameplay
- Winner detection
- Draw detection
- Restart button
- Clean and organized UI

## ⭐ Bonus Features

You can also add:

- Scoreboard
- Sound effects
- Dark mode
- Animations
- AI opponent

---

# 📂 Rules

- Each contributor must create a separate folder using their name or GitHub username
- Add all project files inside your folder
- Add a `README.md` file for your project
- Include your live project link inside your README file
