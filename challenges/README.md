# Weekly Challenges 🧠

This section contains weekly coding challenges designed to help developers practice real-world skills, improve problem-solving abilities, and collaborate with the community.

A new challenge will be added regularly inside its own folder.

---

# 🚀 Purpose

The goal of these challenges is to help contributors:

- Practice consistently
- Improve coding skills
- Build portfolio projects
- Learn collaboration
- Explore different technologies
- Gain real-world development experience

---

# 📂 Structure

Each weekly challenge has its own folder.

Example:

```bash
challenges/
│
├── README.md
├── week-1-challenge/
├── week-2-challenge/
└── week-3-challenge/
```

---

# 🤝 How To Participate

1. Open the current weekly challenge
2. Read the challenge requirements
3. Create your own solution folder
4. Add your project files
5. Add your live demo link inside your README file
6. Submit your Pull Request

---

# 📌 Contributor Structure

Each contributor should create a folder using their name or GitHub username.

Example:

```bash
week-1-challenge/
│
├── ahmedtalaat-dev/
├── mohamed-dev/
└── sara-ui/
```

---

# 🌟 Requirements

Each contribution should include:

- Clean project structure
- README file
- Project description
- Technologies used
- Live demo link

---

# ❤️ Keep Building

Consistency and practice are the keys to becoming a better developer 🚀
