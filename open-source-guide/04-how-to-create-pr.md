# How to Create a Pull Request (PR) 🔀

A Pull Request is how you submit your changes to a project.

---

## 🧭 Steps

### 1. Fork repository
Click "Fork" on GitHub.

### 2. Clone it
```bash
git clone https://github.com/your-username/repo.git
```

### 3. Create branch
```bash
git checkout -b fix-bug
```

### 4. Make changes
Edit files and improve code.

### 5. Commit changes
```bash
git commit -m "fix: resolved bug"
```

### 6. Push branch
```bash
git push origin fix-bug
```

### 7. Open Pull Request
Go to GitHub → click "Compare & Pull Request"

---

## 🧠 Good PR Tips
- Write clear title
- Explain what you changed
- Keep PR small
- Reference issues if needed
