# What is Open Source? 🌍

Open Source means software whose source code is freely available for anyone to view, use, modify, and share.

---

## 💡 Key Idea

Instead of keeping code private, developers share it with the world so others can:

- Learn from it
- Improve it
- Fix bugs
- Build new features

---

## 🚀 Why Open Source is Important

- Encourages collaboration
- Helps developers grow faster
- Powers most modern software (Linux, React, VS Code)
- Builds global developer communities

---

## 🧠 In Simple Words

Open Source = "Code made by people, for people, to improve together"
