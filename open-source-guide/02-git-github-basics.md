# Git & GitHub Basics 🧑‍💻

---

## 📌 What is Git?

Git is a version control system that tracks changes in your code.

---

## 📌 What is GitHub?

GitHub is a platform to host Git repositories online.

---

## 🔑 Basic Git Commands

### Initialize repo
```bash
git init
```

### Clone repo
```bash
git clone https://github.com/ahmedtalaat-dev/OpenSourceHub.git
```

### Check status
```bash
git status
```

### Add files
```bash
git add .
```

### Commit changes
```bash
git commit -m "message"
```

### Push to GitHub
```bash
git push origin main
```

---

## 🌍 Why Git is Important
- Tracks changes
- Allows collaboration
- Prevents code loss
- Enables teamwork
