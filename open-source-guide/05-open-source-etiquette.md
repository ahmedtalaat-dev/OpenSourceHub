# Open Source Etiquette 🤝

Etiquette means how you behave in a community.

---

## 🌟 Good Behavior

- Be respectful
- Help beginners
- Give constructive feedback
- Accept criticism
- Communicate clearly

---

## 💬 Communication Rules

- Use polite language
- Avoid insults
- Stay professional
- Be patient with others

---

## 🚀 Golden Rule

"Treat others like you want to be treated"

---

## 🧠 Remember

Open source is built on collaboration, not competition.
