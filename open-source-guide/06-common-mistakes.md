# Common Mistakes in Open Source ❌

---

## 🚫 1. Large Pull Requests

Too many changes in one PR makes review hard.

---

## 🚫 2. No description

Always explain what you changed.

---

## 🚫 3. Ignoring guidelines

Each project has CONTRIBUTING rules—read them.

---

## 🚫 4. Wrong branch usage

Don't commit directly to main branch.

---

## 🚫 5. Unclear commit messages

Bad:
```bash
fix stuff
```

Good:
```bash
fix: resolve navbar bug on mobile
```

---

## 🚫 6. Not testing code

Always test before pushing.

---

## 💡 Final Tip

Small, clean, well-documented contributions = higher chance of acceptance 🚀
