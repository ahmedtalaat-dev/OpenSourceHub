# Courses 📚

This section contains community-created courses and learning materials designed to help developers learn different technologies step by step.

Contributors can create structured text-based courses, share knowledge, and help others grow in their development journey.

---

# 🎯 Purpose

The goal of this section is to:

- Share free learning content
- Help beginners learn effectively
- Organize educational resources
- Encourage community teaching
- Build a collaborative learning environment

---

# 📂 Course Structure

Each course should have its own folder.

Example:

```bash
courses/
│
├── html-course/
│   ├── README.md
│   ├── lesson-1.md
│   ├── lesson-2.md
│   └── exercises/
│
├── javascript-course/
└── react-course/
```

# 🤝 How To Contribute

You can contribute by:

- Creating new courses

- Fixing mistakes

# 📌 Course Guidelines

Please make sure your course:

- Is well organized
- Uses simple explanations
- Includes examples
- Has clear lesson structure
- Is beginner friendly
- Follows repository structure
