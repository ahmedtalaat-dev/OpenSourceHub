# Lesson 01 - Introduction to HTML 🌐

## What is HTML?

HTML stands for **HyperText Markup Language**.

It is the standard language used to create web pages.

---

## Why HTML is Important?

- It gives structure to web pages
- It defines elements like headings, paragraphs, images, and links
- It is the foundation of all websites

---

## Basic HTML Example

```html
<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello World</h1>
    <p>This is my first HTML page.</p>
  </body>
</html>
